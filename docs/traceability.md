# Traceability matrix

Every FR and NFR in `INTERVIEWTREA-PHASE1-VIEWER.md` gets a row. Rows are added in the
same change that satisfies the requirement, not retrofitted at the end.

A row marked `Manual` has no automated test and says how it was verified instead.
Empty and honest beats populated and fabricated.

| FR-608 (camera) | Orbit, zoom and pan an orthographic camera | `Camera3D`, holding a target, azimuth, elevation and a view height in millimetres - not a position and not an accumulated matrix, for the same reason the Phase 1 reslice frames hold axes rather than a rotation history.
