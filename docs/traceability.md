# Traceability matrix

Every FR and NFR in `INTERVIEWTREA-PHASE1-VIEWER.md` gets a row. Rows are added in the
same change that satisfies the requirement, not retrofitted at the end.

A row marked `Manual` has no automated test and says how it was verified instead.
Empty and honest beats populated and fabricated.

| FR-307 | Oblique reslicing: dragging a crosshair arm rotates the reslice plane, dependent viewports update live | Three parts. `Vector3D.RotatedAbout` is Rodrigues' formula, written out rather than assembled as a matrix because the frame stores its axes and turns them in place, so drags compose in the stored state. `ReslicePlane.Through` gained an overload taking the two axes rather than looking them up, and the enum overload now delegates to it so the oblique and standard paths cannot drift apart; the existing corner-projection sizes a tilted footprint by the same arithmetic. `MainViewModel` holds one row/column axis pair per orientation and `RotateAbout` turns the two that are not the dragged pane's, both by the same angle about its normal. `ViewportControl` hit-tests the arms, converts pointer angle to rotation, and draws each crosshair line along `P.Normal x Q.Normal` | `Vector3DRotationTests` (12, including handedness, composition, and a 30-degree case whose expected value is irrational so it cannot be met by arithmetic exact only at quarter turns); `ReslicePlaneTests.TheAxesOverloadReproducesTheStandardPlane`, `AQuarterTurnWithinThePlaneSwapsWidthAndHeight`, `TiltingTheAxesTiltsTheNormalByTheSameRotation`, `ATiltedPlaneCoversTheLongerChordThroughTheVolume`, `TheIntersectionOfTwoPlanesLiesInBothOfThem`, `RotatingAPlaneTurnsItsCrosshairArmByTheSameAngle`, `TurningTheOtherTwoPlanesKeepsTheTriadOrthogonal`.
